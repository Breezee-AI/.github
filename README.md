# Breezee-AI/.github

Shared settings for every Breezee-AI repository.

- **Issue forms** (`.github/ISSUE_TEMPLATE/`): Decision, Defect, Feature, Plan and Task. Every repository without forms of its own uses these. The standard behind them is the brain's `standards/company/issues.md`.
- **Secret scan** (`.github/workflows/`): the organisation requires it here too.

This repository is public: GitHub only shares forms from a public one. Never put anything private in it.
